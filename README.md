# GymLog 健身追蹤

免費健身追蹤 webapp — 參考 [Gainflow](https://www.gainflow.app) 概念整成。**免安裝、無後端、資料存喺你嘅瀏覽器(localStorage),完全免費。**

## 功能

- **儀表板** — 本週統計(訓練次數/訓練量/組數/次數)、活動熱力圖、近 12 週訓練量圖、肌群分布、最新 PR
- **訓練紀錄** — 60+ 動作庫(可搜尋、按肌群篩選、自訂動作)、鍵盤快速紀錄(重量 → Enter → 次數 → Enter 自動開組)、「上次」參考、自動建議重量、**自動 PR 偵測**(重量/1RM/訓練量)
- **課表** — 將訓練儲存為課表,一鍵開始
- **歷史** — 按月份瀏覽、展開睇詳情、複製成新訓練、刪除
- **進度** — 每個動作嘅估算 1RM 走勢圖 + 最佳重量/1RM/訓練量 PR
- **量測** — 體重紀錄 + 趨勢圖
- **資料** — CSV 匯出/匯入(支援 GymLog / Hevy / Strong 格式)、公斤/磅切換
- **PWA** — 可安裝到主畫面,離線可用

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 產出 dist/
```

## 技術

React 18 + Vite 5,純前端,無任何依賴嘅圖表(手寫 SVG)。資料只存 localStorage,匯出 CSV 即可備份/搬機。
